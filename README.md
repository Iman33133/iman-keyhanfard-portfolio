# Iman Keyhanfard — Bilingual Editorial Portfolio

A responsive, static personal portfolio website in English and Persian.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Use the language switcher in the top-right area to switch between English and Persian.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive editorial design
- `script.js` — English/Persian language switcher

## Before publishing
Please verify the contact email and every career description. The contact email is a placeholder (`YOUR_EMAIL_ADDRESS`); replace it in `index.html` with the address you want to publish.
The current experience entries are intentionally concise. Add links to approved public work samples, video packages, and published reports before sharing the site with employers.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `iman-keyhanfard-portfolio`.
3. Upload the three website files (`index.html`, `styles.css`, `script.js`) to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will show the public website address after deployment.

No build tools or server are required.
