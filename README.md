# Iman Keyhanfard — Bilingual Editorial Portfolio

A responsive, bilingual (English/Persian) portfolio for a Tehran-based journalist, senior news producer and political researcher.

## Website files
- `index.html` — structure and portfolio content
- `styles.css` — responsive editorial design
- `script.js` — English/Persian language switcher and translations

## Current content
- Professional profile and selected career history
- Editorial, field-production, research and translation capabilities
- Selected public LinkedIn posts, clearly labeled as public-feed samples
- Direct email, phone and LinkedIn contact links
- English and Persian versions

## Publishing
The site is a static website and requires no build step. It can be hosted free on GitHub Pages or Cloudflare Pages.

## Notes
The hero currently uses an original editorial graphic rather than a generic stock portrait. A professional headshot can be added when the owner supplies or confirms the exact image to publish.
